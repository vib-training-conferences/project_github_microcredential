# Explanation of the concepts Clone, Branch and Fork

**Name:** Evy Goossens

## Clone

A copy of the github repository on your local computer, including all files and history. You can work in it and sync back to the online repository.

## Branch

Branches are created for experimenting, or working with collaborators on the project. Branch and main can be merged afterwards. 
- The folder structure you see in the explorer, is the one from the branch. If you create a document in a branch, and go move to another branch, this document is not visible anymore
- You have to push each branch separately. If you push in main, the other branches will not be pushed (and vice versa)

## Fork

A copy of another repository created in your own account. Changes that are made do not affect the main repository. You can merge it back with the original repository using pull requests.
